# Octane

**We make quietly useful software.**

Octane is an independent studio building products across food, money,
productivity, and policy. Some commercial, some open — all made carefully,
by a small team, on no one's timeline but our own.

## Products

| Project | What it is |
| --- | --- |
| **[Eatables](https://eatables.octane.team/)** | A discovery and review platform for finding food worth driving for. |
| **[Allocat](https://allocat.octane.team/)** | Envelope-style budgeting that makes the math of your month feel obvious. |
| **[Glyphs](https://glyphs.octane.team/)** | A clipboard manager that remembers everything you copy. |
| **[Vyuham](https://vyuham.octane.team/)** | A readiness tool that helps Indian businesses prepare for DPDPA 2023. |
